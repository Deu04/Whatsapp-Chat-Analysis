# WhatsApp Chat Analyzer 📊

A powerful WhatsApp Chat Analysis web application developed using Python and Streamlit that helps users gain meaningful insights from their WhatsApp chat exports.

## Features

* 📈 Chat Statistics Dashboard

  * Total Messages
  * Total Words
  * Media Shared
  * Links Shared

* 👥 User Activity Analysis

  * Most Active Users
  * User Contribution Percentage

* 💬 Word Analysis

  * Most Frequently Used Words
  * Stop-word Filtering

* 😀 Emoji Analysis

  * Most Used Emojis
  * Emoji Distribution Visualization

* 📅 Timeline Analysis

  * Monthly Activity Trends
  * Daily Activity Trends

* 🗓 Activity Mapping

  * Most Active Days
  * Most Active Months
  * Weekly Activity Insights

* 🔥 Heatmap Visualization

  * User Activity Heatmap by Day and Time

## Technologies Used

* Python
* Streamlit
* Pandas
* Matplotlib
* Seaborn
* Regular Expressions (Regex)
* URLExtract
* Emoji Library

## How It Works

1. Export a WhatsApp chat without media.
2. Upload the exported `.txt` file into the application.
3. The system processes the chat data.
4. Interactive visualizations and analytics are generated instantly.
